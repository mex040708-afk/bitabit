# Bitabit

Servicio de streaming de música casero. Sirve una biblioteca propia a un círculo cerrado de personas y entrega cada canción **bit a bit**: el archivo original sin pérdida, sin remuestrear ni recodificar.

> **Estado:** en preparación. Todavía no hay código.

## Piezas previstas

| Pieza | Tecnología |
|---|---|
| Servidor | Go |
| Base de datos | PostgreSQL |
| App Android | Java + Media3 |
| App de escritorio | Java (JavaFX) + mpv |
